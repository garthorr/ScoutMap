    Upload Source File

    City of Dallas GIS Address Points
    1. Visit the Dallas Open Data portal at dallasopendata.com
    2. Search for "Address Points" or browse the GIS / Maps category
    3. Export as CSV or GeoJSON
    4. Select the file below and import
    DCAD Appraisal / Parcel Data
    1. Go to the Dallas Central Appraisal District site at dcad.org
    2. Navigate to Appraisal Data Downloads (usually under Commercial Services)
    3. Download the residential parcel/appraisal CSV for your target area
    4. Select the file below and import
    Choose the public data source that matches your file CSV, JSON, or GeoJSON exported from the data portal Optional label to identify this import batch

    CSV Format Guide

    Upload a CSV file with a header row. Required column: name. Optional column: scout_id. Extra columns are ignored. Duplicate names are skipped. Sign-in codes are created for you.
